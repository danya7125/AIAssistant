# AI Assistant — SQLite + инженерная валидация ТЗ

Плагин читает локальную `materials.sqlite` напрямую через системную `winsqlite3.dll` и `ctypes` на Windows 10/11. Python `sqlite3`, QtSql/QSQLITE и дублирующие JSON не нужны.

## Новая проверка материалов

Инструмент `validate_material_against_requirements` принимает:
- `materials`: точные названия или ID материалов из базы (1–12);
- `requirements`: список обязательных критериев (1–25);
- `operating_conditions`: температура, состав рабочей среды, pH, часы работы и другие условия.

Каждый критерий получает `PASS`, `FAIL` или `UNKNOWN`. Численное сравнение (`numeric_status`) не равнозначно подтверждению работы при другой температуре/в другой среде. Результат сопровождается исходным значением и `source_path` из JSON Stereotech. Нельзя приравнивать `удлинение при максимальном усилии` к `удлинению при разрыве`, `Vicat` к температуре эксплуатации или свойства XY к ZX. Обозначение химстойкости `(+)` не означает подтверждённые испытания; другая концентрация, смесь, температура и выдержка требуют отдельной проверки.

**Подбор по ТЗ:** если в запросе явно просят выбрать/сравнить материал, итоговое техническое заключение формируется программой на основе результата валидатора. Если AI не вызвала инструмент, она не сможет выдать одобрение как проверенное. Если текст ТЗ содержит критерий, отсутствующий в вызове, вывод помечается неполным. Это защита от ряда ошибок, **но не гарантирует**, что AI безошибочно извлечёт все требования из произвольного текста.

## Пример проверки

Напиши в чат:

> Подбери материал по ТЗ: плотность не выше 1,2 г/см³, модуль упругости в XY не ниже 4500 МПа, прочность в XY не ниже 50 МПа, удлинение при разрыве минимум 2,5%, водопоглощение за 24 часа максимум 0,05%, Vicat B/50 Н от 130 °C. Работа при +85 °C, водно-гликолевый теплоноситель pH 9,5–10,5, 8000 часов в год. Сравни HighTemp PPS G40, Fiberpart PC G20 и Fiberpart PA6 G30. Ничего не меняй в настройках.

По данным встроенной базы PPS G40 получит `FAIL` по плотности (1,65 > 1,2), PC G20 `FAIL` по модулю XY (2085 < 4500), а PA6 G30 останется `UNKNOWN` по ряду критериев. Даже при численном PASS свойства при 85 °C / 8000 ч будут `UNKNOWN`, если подходящих испытаний нет.

## Установка

1. Полностью закрой STE Slicer.
2. Сделай копию текущей папки `AIAssistant`.
3. Распакуй `AIAssistant` из архива **вместо** прежней папки, избегая вложенности `AIAssistant/AIAssistant`.
4. Перезапусти STE Slicer, открой AI Assistant и проверь пример выше.

Файл `materials.sqlite` открывается **только для чтения**. `MaterialValidator.py` — проверка ТЗ; `SettingsTools.py` — регистрация нового инструмента; `AgentClient.py` — правила и безопасная выдача результата. Остальные операции слайсера не менялись. Тестирование выполнено в изолированном Python, без реального запуска в STE Slicer.
