# AI Assistant для SteSlicer (Stereotech 3D / 5D)

Интеллектуальный инженерный плагин-помощник для слайсера **SteSlicer 7.10** (форк Ultimaker Cura / Uranium для принтеров компании **Stereotech**). 

Плагин автоматизирует подбор материалов по техническому заданию (ТЗ), анализ ориентации деталей на столе, оптимизацию параметров нарезки для классической 3D и 5-осевой 5D-печати, а также мониторинг нарезки и экспорт готового G-кода.

## 🧩 Назначение ключевых компонентов

### 1. Ядро логики и агент (`AgentClient.py`, `DomainKnowledge.py`)
* Анализирует запросы пользователя и строгие технические задания (ТЗ).
* Автоматически извлекает рабочие условия: температурный диапазон, контакт с химией (масла, гликоли, щелочи), тип механических нагрузок (удары, трение, растяжение).
* Подбирает оптимальный материал из матрицы **Stereotech** (`Fiberpart`, `Enduse`, `Sealant`, `HighTemp`).
* Различает 3D и 5D режимы печати, определяя необходимость вращения детали или ориентации на оправку.

### 2. Управление параметрами и сценой (`SettingsTools.py`, `SceneTools.py`, `OrientationAnalysis.py`)
* **Безопасное применение настроек:** Пакетное изменение параметров слайсера с валидацией активности ключей и автоматическим откатом при сбоях.
* **Автоориентация:** Обнаружение деталей, «стоящих на ребре» (крыльчатки, шкивы, диски), и их автоматический переворот на 90° для надежного сцепления со столом.
* **Поддержка 5D-печати:** Корректная обработка цилиндрических (`G56`) и пространственных траекторий без принудительного сброса в 3D.

### 3. Мониторинг и экспорт (`SliceMonitor.py`, `AutoExport.py`)
* Подключение к событиям ядра `CuraEngine` (`slicingStarted`, `processingProgress`, `backendStateChange`).
* Отображение реального прогресса нарезки в процентах в интерфейсе чата.
* Автоматическая сборка, добавление метаданных в заголовок и экспорт скомпилированного `.gcode` в отдельную подпапку проекта в `output/`.

### 4. Пользовательский интерфейс (`web/`, `ChatWindow.py`, `WebServer.py`)
* Локальный независимый HTTP-сервер обслуживает интерфейс без внешних зависимостей.
* Поддержка загрузки и анализа файлов на вход: чертежи/фото (`JPG`, `PNG`) и 3D-модели (`STL`, `OBJ`, `3MF`).
* Интерактивная 3D-визуализация моделей прямо в диалоге через `model-viewer.js`.

## ⚙️ Технические требования и среда

* **Платформа:** Windows 10 / 11 (x64).
* **Слайсер:** SteSlicer версии 7.10 (базируется на Uranium / CuraEngine).
* **Интерпретатор Python:** Встроенный в SteSlicer Python 3.5 (все модули строго поддерживают синтаксис Python 3.5, без f-строк).
* **Выходной артефакт:** Готовые файлы управляющих программ `.gcode` с поддержкой кинематики Stereotech 5D (оси $A$ и $C$).
